# 淘宝用户行为分析与推荐系统

基于 Python + Pandas 的端到端电商用户行为分析平台，对阿里巴巴淘宝用户行为数据集（约1亿条交易记录）进行深度挖掘，实现用户价值分层、异常行为检测和个性化推荐。

## 数据集

- **名称**：User Behavior Data from Taobao for Recommendation
- **来源**：阿里云天池
- **链接**：https://tianchi.aliyun.com/dataset/649
- **规模**：约1亿条记录，98万+用户，400万+商品

## 核心功能

### 1. 用户转化漏斗分析
追踪用户从浏览(PV) → 收藏(Fav) → 加购(Cart) → 购买(Buy)的完整转化路径，计算各环节转化率。

### 2. RFM用户价值分层
- **R (Recency)**：最近一次购买距今天数
- **F (Frequency)**：购买频次
- **M (Monetary)**：消费金额
- 采用5分位数分箱 + 8类用户分层算法
- 输出分群：重要价值客户、重要发展客户、重要保持客户、重要挽留客户等

### 3. 多维度异常检测
| 检测类型 | 检测逻辑 |
|---------|---------|
| 高频行为异常 | 分行为类型的日操作阈值检测 |
| 时间模式异常 | 凌晨1-5点异常活跃检测 |
| 行为序列异常 | 疑似刷单、疑似爬虫识别 |
| 统计异常 | 基于Z-Score的异常值检测 |

### 4. 协同过滤推荐系统
- Item-based协同过滤：基于商品共现构建相似度矩阵
- TF-IDF加权：热门商品降权，避免"哈利波特效应"
- 时间衰减：近期行为权重更高
- 冷启动处理：新用户降级到热门推荐

## 技术亮点

- **流式数据处理**：分块读取（50万行/块）+ 增量聚合 + 定期GC，高效处理亿级数据
- **可配置时间窗口**：各模块独立时间窗口，自动适配数据范围
- **分层采样**：按用户活跃度分层采样，避免过采样偏差
- **内存优化**：使用int32、category等紧凑数据类型

## 快速开始

### 环境要求
- Python 3.8+
- Pandas
- NumPy

### 安装依赖
```bash
pip install pandas numpy
```

### 运行
1. 下载数据集并解压到项目目录
2. 修改 `CONFIG['csv_path']` 为数据集路径
3. 运行主程序：
```bash
python user_behavior_analysis.py
```
